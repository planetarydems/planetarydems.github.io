MESA

Mars Elevation from Shading and Altimetry

A global digital elevation model of Mars on an 18 m grid. Elevation is predicted from the shading in 45,570 Context Camera (CTX) images with a neural network and leveled to MOLA laser altimetry.

Data access

Reading subsets of the COG

MESA is distributed as a single 1.4 TB Cloud-Optimized GeoTIFF (COG). Subsets are read with HTTP range requests in GDAL, rasterio, or rioxarray. Only the 512 × 512 pixel tiles that intersect the requested area are transferred. In a test, ~12 MB were transferred for a 35 × 30 km subset at Jezero crater.

Prototype. Hosting is in preparation. The file addresses below are placeholders. The code was tested on a subset with the same file layout.

The four products are defined on one grid (global equirectangular, Mars sphere). Resampling is not required to overlay them.

1. Select an area

Download for QGIS or ArcGIS

The ZIP contains the DEM and the mask of the selected area as GeoTIFFs, each with a world file (.tfw) and a projection file (.prj). The subset is cut from the COG in the web browser. Command-line tools are not required.

Browser downloads are limited to 800 MB of raw data. Larger areas are read in QGIS (step 3) or Python (step 4).

2. Open the DEM in a GIS

QGIS free, qgis.org

  1. Unzip the download.
  2. Drag …_mesa_dem.tif into the QGIS window, or use Layer ▸ Add Layer ▸ Add Raster Layer.
  3. If a red “No transform available” message appears, right-click the layer and choose Layer CRS ▸ Set Project CRS from Layer. Then close the message.
  4. For shaded relief, right-click the layer and choose Duplicate Layer. In Layer Properties ▸ Symbology, set the lower copy to Hillshade and the upper copy to Singleband pseudocolor at ~50% opacity.

ArcGIS Pro

  1. Unzip the download.
  2. On the Map tab, click Add Data and select …_mesa_dem.tif.
  3. Right-click the map in the Contents pane and open Properties ▸ Coordinate Systems. Under Layers, select the coordinate system of the MESA layer (Mars equirectangular) and click OK. Remove the Earth basemap.
  4. For shaded relief, open Imagery ▸ Raster Functions ▸ Surface ▸ Hillshade and select the DEM as input.

The coordinate system is stored in each GeoTIFF. The .tfw and .prj files are included for software that reads world files.

3. Larger areas: stream the COG in QGIS

Areas beyond the browser limit are read directly from the COG in QGIS. Only the tiles in view are transferred.

  1. Open Layer ▸ Add Layer ▸ Add Raster Layer. Select Protocol: HTTP(S), cloud, etc., keep the type HTTP/HTTPS/FTP, and paste the DEM address into URI. Click Add.
  2. Zoom to the area of interest.
  3. Right-click the layer and choose Export ▸ Save As. Under Extent, click Map Canvas Extent or draw a box on the map. Keep the resolution at 18 m, enter a file name, and click OK.

Large regions from overviews
The same surface is stored at coarser pixel spacing in 12 overview levels. At level 3 (288 m pixels), a 30° × 30° region is ~6,200 pixels across.

Infilled pixels
3.6% of the surface is infilled, in areas without usable CTX images. Infilled pixels are suitable for context. They are unsuitable for measurements of small landforms.

        

      
Square pixels in meters
Pixels of the global grid are elongated east–west away from the equator. Reprojection to a projection centered on the area is recommended before distances or slopes are measured.

        

      
HTTP read settings
With these GDAL settings, the directory listing is skipped, requests for adjacent tiles are merged, and connections are reused.
